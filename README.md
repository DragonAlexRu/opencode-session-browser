# OpenCode Session Viewer

Просмотрщик выгрузок сессий [opencode](https://opencode.ai): один HTML-файл, без сервера и зависимостей. Помогает разбирать диалоги с локальной моделью и выбирать из них фрагменты для анализа более сильной моделью (например, чтобы составить скиллы для младшей модели).

Файлы обрабатываются только локально в браузере.

## Запуск

1. Выгрузите сессию:
   ```
   opencode export <session-id> > ses_xxx.json
   ```
   Сессии субагентов выгружаются так же, по отдельности. Их id видны в блоках «Субагент», там же есть кнопка копирования готовой команды.
2. Откройте `opencode-session-viewer.html` в браузере (Chrome, Edge или Firefox) и перетащите в окно один или несколько `.json`. Можно и через кнопку «Открыть файлы…».

## Возможности

- **Фильтр по видам блоков:** промпты пользователя, ответы модели, мысли, вызовы инструментов (с отбором по конкретному инструменту), вызовы субагентов, изменённые файлы, шаги и токены, ошибки. Есть пресеты: «Диалог», «Диалог + мысли», «Работа (без вывода)», «Всё».
- **Цвет и подсветка:** у каждого вида свой цвет. Подсвечиваются BSL (1С), XML, JSON, shell и diff, есть бейджи exit-кода, статуса и длительности. Длинный вывод свёрнут.
- **Сессии субагентов:** если их выгрузки загружены, они встраиваются прямо под вызовом `task` или открываются отдельно.
- **Проблемные места:** статус `error`, `exit ≠ 0`, совпадение вывода с RegExp-шаблоном (настраивается) или повтор одного и того же вызова подряд. Режим «Только проблемы ± N блоков контекста».
- **Поиск** с подсветкой и переходом по совпадениям (`/` — перейти в поиск, `Enter` / `Shift+Enter` — следующее / предыдущее совпадение).
- **Выбор и копирование:**
  - чекбокс у каждого блока, `Shift`-клик выделяет диапазон, у каждого хода есть кнопка «выбрать ход», можно выбрать все проблемные;
  - «Копировать», «Скачать», «Предпросмотр» (текст можно поправить перед копированием);
  - в выгрузку попадают только **видимые** блоки, то есть фильтры действуют и на копирование. Если ничего не выбрано, копируется всё видимое;
  - два формата: **XML-теги для LLM** (`<user>`, `<thinking>`, `<tool name="bash" exit="1">`, `<subagent>`, `<note>`…) и **Markdown**;
  - вывод инструментов обрезается до N строк (сохраняются начало и конец), каталог проекта в путях заменяется на `.`;
  - кнопка ⧉ копирует один блок;
  - обычное выделение мышью тоже работает: служебные подписи и кнопки в выделение не попадают.
- **Заметки** (✎) к любому блоку попадают в выгрузку. Например: «здесь модель не знала формат Form.xml». Заметки хранятся в `localStorage` браузера.
- Светлая и тёмная тема.
